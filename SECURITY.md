# Security and vehicle safety

This repository is an experimental, read-only OBD-II Android prototype, **not** a qualified ECU service tool. A vehicle module may behave unpredictably even in response to read requests. Use on authorized vehicles only, parked, with the vehicle manufacturer procedures followed.

Do not submit publicly: real VINs, registration/ownership records, diagnostic logs containing identifying data, API credentials or security-sensitive vehicle identifiers.

Report vulnerabilities privately to repository maintainers using GitHub's private vulnerability reporting if enabled. Do not post exploitable findings or vehicle-specific secrets in public issues.

No programming, coding, control commands or security-access bypass is implemented in this release. Do not enable writes or active tests without bench validation, whitelists, physical safety reviews and backup/restore procedures.
